opkg quick reference

opkg is the package manager used on PandA.

CommandDescription
opkg list-installedList all installed packages
opkg install <package> ...Install or replace named packages
opkg remove <package> ...Remove named packages
opkg files <package> ...Show files belonging to named packages
opkg helpShow all available options

For a step-by-step guide to installing packages see Install packages via opkg.
