Panda SDK

A docker image is provided for each machine called panda-sdk-{machine}, for example panda-sdk-pandabox, this contains the SDK built by yocto to be able to build binaries compatible with the panda linux system outside of yocto, this is used only for testing purposes.

Additionally, the sdk installer is also provided to use it in the host directly.
